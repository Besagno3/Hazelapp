# Audio assets

The game plays the **16-bit chiptune set in `16bit/`**, generated by
`tools/assets/audio.py` (re-run `python3 tools/assets/build.py audio` from
`hazel-game/`). Paths are mapped in `SFX_SOURCES` / `MUSIC_SOURCES` in
`src/lib/audio.ts`; a missing file fails silently, so gameplay never breaks.

Audio is **off by default**; players turn on Music / Sound effects in the
in-game menu (📜 → 🔊 Audio).

## `16bit/sfx/` — one-shots
| File | Plays when |
|------|------------|
| `correct.mp3` | a question is answered correctly |
| `wrong.mp3` | a question is answered wrong |
| `attack.mp3` | the hero lunges (attack / spell) |
| `hit.mp3` | the hero takes damage |
| `gate.mp3` | a gate opens (question or key) |
| `chest.mp3` | a treasure chest is opened |
| `levelup.mp3` | the level-up celebration |
| `victory.mp3` | a battle is won |
| `select.mp3` | a hero is picked |

## `16bit/music/` — seamless loops
`title`, `overworld`, `battle`, `boss`, `spire`, `finalBoss`, `victory`
(reserved) — see `trackForScreen` in `src/lib/audio.ts`.

## Older tracks
The earlier player-supplied mp3s (`Overworld.mp3`, `Battle_Music.mp3`, …)
are still in this folder. To use one again, point its entry in
`MUSIC_SOURCES` / `SFX_SOURCES` back at it.
