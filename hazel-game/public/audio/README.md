# Audio assets

The game plays the **16-bit chiptune set in `16bit/`**, generated by
`tools/assets/audio.py` (re-run `python3 tools/assets/build.py audio` from
`hazel-game/`). Paths are mapped in `SFX_SOURCES` / `MUSIC_SOURCES` in
`src/lib/audio.ts`; a missing file fails silently, so gameplay never breaks.

**Music is on by default** — the sign-in screen's intro, then the game's
music (browsers hold all sound until the first tap or key). **Sound effects are
off by default.** Players switch either in the in-game menu (📜 → 🔊 Audio),
and the choice sticks on that device.

## `16bit/sfx/` — one-shots
| File | Plays when |
|------|------------|
| `correct.mp3` | a question is answered correctly |
| `wrong.mp3` | a question is answered wrong |
| `attack.mp3` | the hero's Attack swoosh |
| `hit.mp3` | the hero takes damage |
| `gate.mp3` | a gate opens (question or key) |
| `chest.mp3` | a treasure chest is opened |
| `levelup.mp3` | the level-up celebration |
| `victory.mp3` | a battle is won |
| `select.mp3` | a hero is picked |
| `impact.mp3` | an enemy takes damage in battle |
| `enemyAttack.mp3` | the enemy lunges |
| `spell.mp3` | a spell is cast (landed) |
| `heal.mp3` | HP restored (Mend, potions, a healer enemy mending) |
| `guard.mp3` | a guard / shield is raised (Guard, Aegis, Rainbow Ward) |
| `block.mp3` | an enemy hit is fully blocked |
| `shatter.mp3` | a shielded enemy's shield breaks |
| `roar.mp3` | Ember attacks |
| `swap.mp3` | a companion swaps in |
| `charge.mp3` | an enemy gathers power (a telegraphed blow is coming) |
| `streak.mp3` | 3 / 5 correct answers in a row |
| `pair.mp3` | a hero + companion Pair Attack |

## `16bit/music/` — seamless loops
`title`, `overworld`, `town`, `cave`, `shrine`, `battle`, `boss`, `finalBoss`,
`victory` (reserved), plus the Spire's spooky set (`spire`, `spireArchive`,
`spireThicket`, `spireStars`, `spireEngine`) — see `trackForScreen` in
`src/lib/audio.ts`. Each loop is a full song form (A A' B A'', at least 30 s;
today 45–116 s) so it doesn't feel like one phrase on repeat.
The sea has one loop per sea area (`SEA_TRACK`): `sailing`, `shallows`,
`fogbank` — hand-written tunes in the same song form (38–64 s).
The sign-in screen (and the screen after signing out) has its own `intro`
(72 s): a harp-like arpeggio sweeping up and down three octaves, one chord a
bar, that swells from soft ripples to a full climax — a pad, then a tune and
a bass, then a timpani roll — and back down, so the loop comes round without
a jump. Rebuild it alone with `python3 tools/assets/build.py intro`.

## Only what the game plays
Every audio file here is one `SFX_SOURCES` / `MUSIC_SOURCES` points at
(`audio.test` fails on any other). The earlier player-supplied mp3s
(`Overworld.mp3`, `Battle_Music.mp3`, …) were deleted on 2026-10-10 (#116):
nothing played them, and they made it look as if two sets of music were in
use. To get one back: `git log --diff-filter=D -- public/audio` finds the
commit that deleted them.
