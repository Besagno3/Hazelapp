# Hazelapp

Home of **Hazel Quest**, an educational JRPG for kids where every attack,
spell, and block is powered by answering an AI-generated question.

The game lives in [`hazel-game/`](hazel-game/). See its
[README](hazel-game/README.md) for setup, and
[`hazel-game/CLAUDE.md`](hazel-game/CLAUDE.md) for the conventions and the
map of the docs (how each system works is in
[`hazel-game/docs/architecture/`](hazel-game/docs/architecture/)).
